第0章はじめに

0-1　HorrorKit でできること

HorrorKit は、一人称ホラーゲームでよく使う仕掛け（ギミック）を、プログラムを書かずにUnity のインスペクター上で組み立てるためのセットです。

  • 調べる：机・メモ・ラジオなどを E キーで調べ、会話を表示する
  • 拾う：鍵などのキーアイテムを手に入れる（Tab で所持品を確認）
  • フラグ：「メモを読んだ」などの進行状況を記録し、会話や出来事を変化させる
  • 扉：開け閉めできる扉。鍵を持っていれば開く施錠扉
  • ジャンプスケア：幽霊の出現・突進・画面揺れ・強制的に振り向かせる演出
  • 雰囲気：暗い照明・霧・ちらつくライト・懐中電灯・画面効果

0-5　イベントが動くしくみ（ページのルール）

ここが一番大切なルールです。イベントに複数のページがあるとき、HorrorKit は番号の大きいページから順に「出現条件を満たしているか」を調べ、最初に満たしたページだけを使います。

ページ4条件：幽霊を見た
→ まだ見ていない ✕
→
ページ3条件：鍵を持っている
→ 持っていない ✕
→
ページ2条件：メモを読んだ
→ 読んだ ◯ これを使う
→
ページ1条件なし
（見に行かない）

図0-6　ラジオを調べたときの判定の例（メモを読んだ後）

つまり
  • ページ1 には「普段の反応」を置き、条件なしにする（最後の受け皿）。
  • 話が進むほど起きる反応を、後ろのページに足していく。
  • 「一度だけ実行」に印を付けたページは、1回実行するとスキップされ、次に条件を満たす下のページが使われる。

起動方法は3種類あります。

起動方法動くタイミング必要な Collider
調べる（決定キー）プレイヤーが近くで見つめて E を押したとき。画面に「[E] 調べる」が出る通常の Collider（Is Trigger オフ）
エリアに入るプレイヤーが範囲に入った瞬間Is Trigger オンの Collider
自動実行ページが有効になった瞬間（ゲーム開始時や、フラグが変わったとき）。必ず1回だけ不要
注意イベントの実行中はプレイヤーは動けません。会話を最後まで送るとまた動けるようになります。

第1章サンプルのギミックを読み解く

デモにある7つのギミックを、「ゲームでの見え方 → シーン上の場所 → 設定画面 → ポイント」の順に見ていきます。設定画面はマネージャー（第3章）の画面ですが、Hierarchy でオブジェクトを選んだときのインスペクターにも同じものが出ます。

1-1　オープニング（自動実行）

自動実行フェード会話場所：Events / Event_Intro
順コマンド内容
1演出/フェードアウト秒数 0 ＝ 一瞬で真っ暗にする
2会話/メッセージ「……ここは、どこだ。」
3演出/フェードイン2秒かけて明るくする
4会話/メッセージ操作説明（<size=26> で文字を小さく）
ポイント
  • 見た目のない空のオブジェクトに HorrorEvent を付けただけ。Collider も不要です。
  • フェードアウト中でも会話ウィンドウは見えるので、暗闇の独り言が作れます。
  • 会話の文章には <size=26>…</size>（大きさ）や <color=#ff4444>…</color>（色）が使えます。

1-2　机のメモ（拾うアイテム）

調べる一度だけ実行アイテム入手フラグON場所：Environment / Props / Note
ポイント
  • 「アイテム/入手」で所持品に入り、「〇〇を手に入れた。」は自動で表示されます（出したくなければ「通知を出さない」）。
  • 「フラグ/設定」で read_note を ON。これがラジオと棚の反応を変えるスイッチになります。
  • 「制御/オブジェクト表示切替」でメモ自身を消して「拾った」ように見せています。
  • メモは薄くて小さいので、BoxCollider を実物より大きくして狙いやすくしています（シーンの水色の枠）。

1-3　古いラジオ（フラグで会話が変わる）

調べる4ページ出現条件話者名場所：Environment / Props / Radio

ラジオは同じ物なのに、ゲームの進み具合で反応が4通りに変わります。0-5 のルールそのものです。

ページ出現条件一度だけ反応
1 通常なし「古いラジオだ。」「ノイズしか聞こえない。」
2 メモを読んだ後read_note が ON◯ラジオの声（話者「ラジオ」）→ 懐中電灯が明滅 → heard_radio を ON
3 鍵を持っているrusty_key を所持「……もう……遅い……」
4 あれを見た後saw_ghost が ON「ラジオは完全に沈黙している。」
反応の移り変わり
  1. 最初に調べる → ページ1（ノイズ）
  2. メモを読んで調べる → ページ2（声）。一度だけなので、もう一度調べると ページ1 に戻る
  3. 鍵を拾ってから調べる → ページ3
  4. 幽霊を見た後に調べる → ページ4（ページ3より番号が大きいので優先）
ヒント会話の「話者（任意）」に名前を入れると、ウィンドウの左上に名前の札が出ます。空欄なら主人公の心の声のような表示になります。

1-4　廊下の棚（条件付きで鍵が見つかる）

調べる2ページ見た目と判定が別場所：Environment / Props / Shelf
ポイント
  • メモを読む前は ページ1 しか満たさないので、鍵が見えていても手に入りません。「ヒントを見てから見つかる」作りです。
  • 棚は複数の板でできていて、HorrorEvent は親の Shelf に付いています。どの板を調べても親のイベントが動きます。
  • 鍵の見た目（RustyKey）は別オブジェクト。「表示切替」の対象にそれを指定して消しています。

1-5　廊下の幽霊（エリア＋ジャンプスケア）

エリアに入る一度だけ実行ジャンプスケア場所：Events / Event_GhostArea ＋ JumpScare_Ghost

このギミックは2つの部品でできています。

部品役割
Event_GhostArea（HorrorEvent）いつ起きるかを決める。廊下をふさぐ Is Trigger の箱。「鍵を持っている」ときだけ、一度だけ動く
JumpScare_Ghost（JumpScare）何が起きるかを決める。幽霊の出現・突進・画面揺れなど
JumpScare の項目意味デモの値
Scare Object演出中だけ現れる物（普段は非表示にしておく）Ghost
Lunge Target／Lunge Time突進の行き先と、そこまでの秒数LungeTarget／0.3秒
Force Look／Look Pointプレイヤーの視点を強制的に向けさせる点幽霊の頭（Head）
Fov Kick一瞬ズームする量（マイナスでズームイン）-14
Impulse／Impulse ForceCinemachine の画面揺れと強さ1.2
Scare Sound驚かせる音（未設定なら無音）なし
Flicker Flashlight懐中電灯を明滅させるオン
Duration／Play Once演出の長さ／一度しか出さない1.3秒／オン
ヒント演出の後に「待機 0.5秒」を入れてから独り言を出すと、驚いた後の間が生まれます。

1-6　鍵のかかった扉

Door コンポーネント鍵アイテム場所：Environment / Doors / Door_Locked

扉は HorrorEvent ではなく、専用の Door コンポーネントです。ページを作らなくても、項目を埋めるだけで施錠扉になります。

1-7　デモ終了（暗転演出）

エリアに入るフェード場所：Events / Event_End
ポイントフェードアウトで真っ暗にしてから文章を出すと、場面転換やエンディングの雰囲気になります。最後にフェードインを入れ忘れると、画面が暗いまま戻らないので注意。

2-1　アイテムとフラグを登録する

アイテムとフラグは、イベントで使う前に HorrorKit > マネージャー（Ctrl+Shift+H）で登録します。登録すると、イベントの設定で一覧から選べるようになります。

  1. アイテムタブを開き、一覧の右下の ＋ を押します。
  2. ID（プログラム用の名前）を半角英数字で決めます。例：battery、old_photo
  3. 表示名（ゲーム画面に出る名前）と説明（所持品画面に出る文）を入れます。
名前の付け方のコツ
  • IDは半角の英小文字・数字・アンダーバーだけにする（例：saw_ghost）。
  • フラグは「〜した」で考えると分かりやすい：read_note（メモを読んだ）、power_on（電気がついた）
  • 説明欄にメモを書いておくと、一覧やドロップダウンに表示されて迷いません。
注意赤く表示された行は、IDが空欄か、他と重複しています。そのままだと正しく動きません。

2-2　調べるだけのオブジェクト

例：「古い絵画を調べると独り言」

  1. 絵画のモデル（または Cube）をシーンに置きます。
  2. その絵画を選び、Add Component で HorrorEvent を追加します。
    または Hierarchy 右クリック → HorrorKit → 調べるイベント で、Collider 付きの空オブジェクトを作り、絵画の前に置いてもOK。
  3. インスペクターに下のような黄色い警告が出たら、「BoxCollider を追加」を押します。
  4. 「実行内容」の ＋ でコマンドを追加し、「会話/メッセージ」を選んで本文を書きます。
  5. 「表示する行動名」を「見る」などに変えると、画面の表示が「[E] 見る」になります。
ヒント会話を複数に分けたいときは、「会話/メッセージ」コマンドを複数並べます。1つの本文の中で改行（Enter）することもできます。

2-3　拾えるアイテム

例：「床の電池を拾う」（1-2 の机のメモと同じ作り）

  1. 2-1 でアイテム battery（表示名「電池」）を登録しておきます。
  2. 電池のモデルに HorrorEvent と Collider を付けます。小さい物は Collider を大きめに。
  3. ページの設定：表示する行動名「拾う」、一度だけ実行にチェック。
  4. コマンドを3つ並べます。
    順コマンド設定
    1会話/メッセージ「床に電池が落ちている。」（省略可）
    2アイテム/入手アイテム：battery
    3制御/オブジェクト表示切替対象：電池自身、「表示する」のチェックを外す
登録を忘れたら先にイベントを作ってしまっても大丈夫です。マネージャーのアイテムタブに「未登録のIDがシーンで使われています」と出るので、「未登録IDをすべて登録」を押せば一括で登録されます。その後、表示名と説明を書き足してください。

2-4　状況で反応が変わるもの（ページを増やす）

例：「冷蔵庫。普段は『空っぽだ』。電気がついた後は『中から音がする…』」

  1. 冷蔵庫にイベントを作り、ページ1に「空っぽだ。」を設定します（条件なし）。
  2. インスペクターの 「＋ 新規ページ」 を押して ページ2 を作ります。
  3. ページ2 の「出現条件」の ＋ で条件を追加し、「フラグがON」「power_on」を選びます。
  4. ページ2 のコマンドに「中から音がする…」を書きます。
  5. 別の場所（ブレーカーなど）のイベントに「フラグ/設定 power_on を ON」を入れます。

2-5　エリアに入ると起きるイベント

例：「廊下を通ると、背後で物音がする」

  1. Hierarchy 右クリック → HorrorKit → エリアイベント。オレンジの箱が付いたオブジェクトができます。
  2. 通路をふさぐように移動し、BoxCollider の Size で箱の大きさを通路に合わせます。
  3. 起動方法が「エリアに入る」、一度だけ実行にチェックが入っていることを確認します。
  4. コマンドに「演出/効果音」「演出/懐中電灯を明滅」「会話/メッセージ」などを並べます。
注意「一度だけ実行」を外すと、範囲に入るたびに毎回起きます。何度も起きてほしいとき以外はチェックを入れておきましょう。

2-6　鍵付きの扉

  1. Hierarchy 右クリック → HorrorKit → ドア。親（蝶番）と子の板（Panel）のセットができます。
  2. 親を、扉の蝶番の位置に置きます（板は親を軸に回ります）。
  3. 開く向きが逆なら Open Angle をマイナスにします（例：-100）。
  4. 鍵を掛けるなら Locked にチェック、Key Item Id で鍵アイテムを選びます。
  5. Locked Message（鍵がないときの文）を書き換えます。
自分の扉モデルを使う
  1. メニューで作ったドアの子 Panel と Knob を削除
  2. 自分の扉モデルを親の子にし、扉の端が親の位置（蝶番）に来るよう位置をずらす
  3. 扉モデルに Collider を付ける
イベントから扉を操作するコマンドの「ドア/開ける・閉める・施錠・解錠」で、イベントから扉を動かせます。例：「エリアに入ると背後の扉がバタンと閉まって施錠される」。この場合、扉の Player Can Use を外すと、プレイヤーは開けられなくなります。

2-7　ジャンプスケア

  1. Hierarchy 右クリック → HorrorKit → ジャンプスケア。
  2. 子の ScareObject（差し替えてください） を削除し、代わりに幽霊のモデルを子に入れます。
  3. 幽霊モデルを非表示（インスペクター左上のチェックを外す）にし、JumpScare の Scare Object に指定します。
  4. 幽霊モデルの Collider は外します（プレイヤーがぶつかって止まるのを防ぐ）。
  5. 突進させるなら空のオブジェクトを行き先に置き、Lunge Target に指定します。
  6. 顔に視点を向けさせるなら、顔の位置のオブジェクトを Look Point に指定します。
  7. Scare Sound に驚かせる音を入れます。
  8. エリアイベント（2-5）のコマンドに 「演出/ジャンプスケア」 を追加し、このジャンプスケアを指定します。
怖くするコツ
  • エリアに「アイテムを所持」などの条件を付け、油断している帰り道で出す
  • 直前に「待機」「懐中電灯を明滅」を入れて溜めを作る
  • 演出後に「フラグ/設定」で見たことを記録し、他の会話を変化させる（ラジオのページ4のように）
固定カメラ演出Cinemachine Camera を別に置いて Focus Camera に指定すると、演出中だけそのカメラに切り替わります。

2-8　ちらつく照明

  1. Hierarchy 右クリック → HorrorKit → ちらつくライト。
  2. 天井などに移動し、Light の Color・Intensity・Range を調整します。
  3. FlickerLight の Flicker Amount（揺らぎ）と Blackout Chance（消える頻度）で性格を決めます。
  4. 電球のモデルがあれば Emissive Renderer に指定します（マテリアルの Emission をオンにしておく）。

既にある Light に「Add Component → FlickerLight」を追加しても同じです。

第3章管理とテスト

3-1　マネージャーを開く

上部メニューの HorrorKit > マネージャー、またはショートカット Ctrl+Shift+H で開きます。5つのタブがあります。

タブできること
アイテムキーアイテムの登録・編集。シーン内で使われている場所の確認
フラグフラグの登録・編集・初期値
イベントシーン内の全イベントの一覧と、その場での編集
会話テキストシーン内の全会話を一覧で編集
デバッグ再生中にフラグ・所持品を切り替え、イベントを強制実行

3-2　イベントタブ（一覧と編集）

  • 左の一覧には、各ページの [起動方法] 条件 → コマンド数 が1行で表示されます。どのイベントが何をするか、ひと目で分かります。
  • 上の検索欄では、イベント名・メモ・会話の本文でも検索できます。
  • 「参照で絞り込み」でアイテムやフラグを選ぶと、それを使っているイベントだけが表示されます。例：rusty_key を選ぶ → 鍵に関係するイベントが分かる。
  • 「シーンで選択」「フォーカス」でシーンビューのその場所へ移動します。
  • 「＋ 調べるイベント」「＋ エリアイベント」で新しいイベントを作れます（シーンビューの中心に置かれます）。

3-3　会話テキストタブ（文章の一括編集）

シーン内のすべての会話を上から順に並べて表示します。左の欄が話者、右が本文で、ここで直接書き換えられます。文章の見直し（誤字・口調の統一）に便利です。扉の施錠メッセージも一番下に表示されます。

ヒント「開く」ボタンで、そのイベントの設定（イベントタブ）へ移動します。

3-4　アイテム／フラグタブ（参照とID変更）

  • 各行の 「シーン内の参照 N 件（選択する）」を押すと、そのアイテム・フラグを使っているオブジェクトがまとめて選択されます。
  • 「参照なし」のものは、どこからも使われていません（作りかけ・消し忘れの確認に）。
IDを変更したいとき
  1. 一覧でIDを書き換える（例：key01 → rusty_key）
  2. タブ下部の「シーン内のID参照を一括置換」に、左に古いID・右に新しいIDを入れて「置換」
これでイベントや扉に設定済みのIDもまとめて書き換わります。IDだけ変えて置換を忘れると、イベント側に「⚠ 未登録」と表示されます。

3-5　デバッグタブ（再生中のテスト）

再生中にだけ使えるタブです。最初から遊び直さなくても、途中の状況をすぐ作れます。

  • フラグ：チェックでその場で ON/OFF。「メモを読んだ状態」などを一瞬で作れます。
  • 所持品：チェックでアイテムを持たせる／取り上げる。
  • イベント：各イベントの「今有効なページ」が表示されます。「実行」でその場から動かなくても実行できます。
  • リセット：フラグ・所持品・「一度だけ実行」の記録を最初の状態に戻します。
「反応しない」ときの確認手順
  1. デバッグタブでそのイベントの行を見る
  2. 「有効なページなし」→ 条件を満たすページがない（条件の設定を確認）
  3. 意図と違うページが有効 → ページの順番や条件を見直す
  4. 意図したページが有効なのに動かない → 起動方法と Collider を確認（第4章）

第4章困ったときは

症状確認すること
Q1. 近づいても「[E] 調べる」が出ない
  • Collider が付いているか。Is Trigger がオフか（オンだと調べられない）
  • 小さすぎないか（Collider を大きく）。距離が遠すぎないか（初期 2.2m）
  • 有効なページの起動方法が「調べる」か、コマンドが1つ以上あるか
  • 条件を満たしているか（デバッグタブで確認）
Q2. エリアに入っても何も起きない
  • Collider の Is Trigger がオンか
  • 起動方法が「エリアに入る」か、条件を満たしているか
  • 「一度だけ実行」で、既に一度起きていないか（デバッグタブの「リセット」で戻せる）
Q3. 思ったページが実行されない 番号の大きいページが優先です（0-5）。条件なしのページを後ろに置くと、それが常に選ばれてしまいます。条件なしのページはページ1に。
Q4. 1つを実行したら、別のイベントまで「実行済み」になった 「一度だけ実行」の記録はシーン名＋階層の位置＋オブジェクト名で区別しています。同じ親の下に同じ名前のイベントがあると同一扱いになります。複製したら名前を変えてください。
Q5. 画面が暗いまま戻らない 「フェードアウト」の後に「フェードイン」を入れ忘れていないか確認してください。
Q6. アイテム欄に「⚠ 〇〇（未登録）」と出る そのIDがマネージャーに登録されていません。アイテム／フラグタブの「未登録IDをすべて登録」で登録できます（2-3）。
Q7. 再生を止めると「Save changes made in Play Mode」と聞かれる Cinemachine の機能で、再生中にスクリプトが動かしたカメラの揺れや画角を保存するか聞いています。Don't Keep を選んでください。毎回出ないようにするには、PlayerCamera (Cinemachine) のインスペクター上部の「Save During Play」のチェックを外します。
Q8. 暗すぎる／明るすぎる 懐中電灯：Player/Flashlight の Light の Intensity。霧：Lighting ウィンドウの Fog の Density。全体：HorrorVolumeProfile の Color Adjustments → Post Exposure。
Q9. ビルドしたゲームで日本語が □ になる 画面表示はパソコンに入っている日本語フォントを使っています。配布する場合は、日本語フォント（例：Noto Sans JP）をプロジェクトに入れ、[HorrorKit HUD] の Font に指定してください。
Q10. 会話中にキャラクターが動けない 仕様です。イベント実行中はプレイヤーの操作が止まります。会話を最後まで送ると動けます。
